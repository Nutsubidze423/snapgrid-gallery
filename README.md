# SnapGrid Gallery

A Next.js image gallery with drag-drop upload, masonry/grid layout, lightbox, and tag filtering.

## Setup

```bash
npm install
npm run dev
```

## Features

- Drag & drop upload
- Grid/masonry layout
- Tag filtering
- Lightbox with captions
- localStorage persistence
